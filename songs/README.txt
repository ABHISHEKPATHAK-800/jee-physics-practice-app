DROP YOUR AUDIO FILES HERE
===========================

Add exactly these six files to this folder:

  song1.mp3
  song2.mp3
  song3.mp3
  song4.mp3
  song5.mp3
  song6.mp3

How they're used in Quiz Mode:
  - Correct answer  -> randomly plays song1, song5, or song6
  - Wrong answer     -> randomly plays song2 or song3
  - song4 is reserved and not auto-played anywhere — use it yourself
    (e.g. wire it to a "test submitted" moment) or ignore it.

Any short mp3 works. If a file is missing, the app just stays silent
for that event instead of breaking — so you can add these whenever
you like, the app works fine without them too.

You can turn sound on/off from the in-app Settings (gear icon).
